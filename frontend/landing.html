📖 SciGraph Documentation

1. Ingesting Documents

Upload PDF, TXT, or Markdown documents via the UI drag-and-drop or use the direct REST API endpoint:

curl -X POST "http://127.0.0.1:8100/upload" \ -H "accept: application/json" \ -F "files=@my-document.pdf"

2. Real-Time Telemetry

Connect to /progress/{job_id} via Server-Sent Events to stream extraction logs, chunk counters, and completion events.

Available Retrieval Modes

  • mix (Recommended): Blends vector cosine similarity with knowledge graph entity traversal for comprehensive answers.
  • hybrid: Combines local multi-hop entity relations with global community summaries.
  • local: Traverses immediate 1-hop and 2-hop neighborhood nodes around query keywords.
  • global: Aggregates macro-level semantic cluster summaries across the whole corpus.

Topological Nodes & Links

The knowledge graph automatically indexes entities into typed nodes with degree centrality and relationship weights.

{ "nodes": [ {"id": "Deep Learning", "type": "concept", "degree": 14}, {"id": "PyTorch", "type": "framework", "degree": 8} ], "links": [ {"source": "PyTorch", "target": "Deep Learning", "weight": 2.5} ] }

⚡ REST API Reference & Code Samples

POST /query • Execute GraphRAG Search

Execute a sub-second grounded question answering query.

curl -X POST "http://127.0.0.1:8100/query" \ -H "Content-Type: application/json" \ -d '{"query": "What is Fine Tuning in AI?", "mode": "mix"}'

GET /graph • Fetch 3D Topology Data

Retrieve nodes and directed relations for 3D visualization.

curl -X GET "http://127.0.0.1:8100/graph?limit=500"

GET /stats • System Health & Storage Metrics

curl -X GET "http://127.0.0.1:8100/stats"
